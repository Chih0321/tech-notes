## Python 實作邏輯

以下是使用 Python 實作剛度矩陣的簡單範例：

```python
import numpy as np

def get_stiffness(E, I, L):
    """
    計算懸臂樑側向剛度
    :param E: 彈性模數 (tf/m2)
    :param I: 慣性矩 (m4)
    :param L: 長度 (m)
    """
    k = (3 * E * I) / (L**3)
    return k

# 實際呼叫
k_value = get_stiffness(2.4e6, 0.005, 4.0)
print(f"剛度值: {k_value:.2f} tf/m")
